# 产品路线图 v3(独立方向,2026-11-20 起)

定位重构:本应用不再对标微信。基于已有设计语言(墨水屏灰度、直角、无阴影)与已建成的能力(文字优先、云端可靠投递、克制的社交面),确立独立产品命题:**一个低刺激、文字优先、数据归用户所有的轻通讯工具**。功能取舍以"是否强化专注与所有权"为准绳,凡属大平台粘性套路(红点轰炸、算法流、无限刷)一律不做。

## 已建成能力盘点(截至 ab8d877)

| 域 | 能力 |
|---|---|
| 账号 | 注册(邮箱验证)、登录、忘记密码、注销(级联清理)、资料门槛引导、协议/隐私页 |
| 关系链 | 防枚举搜索、好友请求(接受/拒绝/取消)、删除好友(单向)、拉黑/解除、黑名单管理、好友资料页 |
| 消息 | 文字收发(realtime)、乐观发送+失败重试、已读回执(read_cursors 水位)、未读角标、撤回(2min)、单方删除、会话左滑删除(message_hides)、断线补拉、在线/离线横幅、PWA 离线壳 |
| 朋友圈 | 发布(含图)、点赞、评论、分页、删除、仅好友可见 |
| 资料 | 头像上传降采样、编辑资料 |
| 工程 | CI(lint+102 单测+11 e2e)、RLS 全开、错误遥测限流上报、加密 DB 备份 workflow、Vercel CD |
| 演示占位 | 通话 UI(标注"演示",无真实通信) |

### M2 图片消息与内容增强(1~2 天)

- [ ] 2.1 **图片消息**:Storage 桶 `message_media`(私有读,签名 URL)+ `messages.attachments jsonb`;发送走 canvas 降采样(复用头像管线),气泡内灰度渲染、点击全屏

### M3 通知与触达(1~2 天,产品价值高)

- [ ] 3.1 **Web Push 通知**:Supabase Edge Function 监听 messages INSERT → Web Push 推送;PWA 已有 sw.js,补 push 事件处理与通知权限引导页

### M4 数据所有权与账号安全(独立产品的核心卖点)

- [ ] 4.1 **个人数据导出**:一键导出全部消息/朋友圈/资料为 JSON+媒体 zip(Edge Function 打包,签名链接下载);在"我的"页常驻入口,作为信任声明
